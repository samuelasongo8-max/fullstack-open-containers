Exercise 11: Redis CLI

## 1. Find the todo counter key

```bash
$ docker exec todo-backend-redis-1 redis-cli KEYS '*'
added_todos
```

## 2. Inspect and set the counter

The counter was `1` before it was changed:

```bash
$ docker exec todo-backend-redis-1 redis-cli GET added_todos
1
```

Set the counter to `9001`:

```bash
$ docker exec todo-backend-redis-1 redis-cli SET added_todos 9001
OK

$ docker exec todo-backend-redis-1 redis-cli GET added_todos
9001
```

## 3. Verify the counter through the Express API

```bash
$ curl http://localhost:3000/statistics
{"added_todos":9001}
```

## 4. Create a todo and verify that the counter increases

```bash
$ curl -X POST http://localhost:3000/todos -H "Content-Type: application/json" -d '{"text":"Exercise 11 Redis counter test","done":false}'
{"text":"Exercise 11 Redis counter test","done":false,"_id":"6ae338d4740cf24943c7effb","__v":0}
```

The statistics endpoint then returned:

```bash
$ curl http://localhost:3000/statistics
{"added_todos":9002}
```

## 5. Delete the counter and test it again

The delete command returned `0`, meaning the key was already absent:

```bash
$ docker exec todo-backend-redis-1 redis-cli DEL added_todos
(integer) 0

$ docker exec todo-backend-redis-1 redis-cli GET added_todos
(nil)
```

After creating another todo, the response contained this ID:

```text
6ae3393b740cf24943c7effd
```

The statistics endpoint then returned:

```bash
$ curl http://localhost:3000/statistics
{"added_todos":1}
```

Redis also contained the recreated counter:

```bash
$ docker exec todo-backend-redis-1 redis-cli GET added_todos
1
```
